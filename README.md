# EtsyThumbnailWeb

日本のEtsyセラー向けの、ブラウザだけで使えるクリップアートバンドル用サムネイル生成アプリです。

## 主な機能

- 複数のPNG素材をアップロード
- ドラッグ＆ドロップ、またはクリックでPNG素材を追加
- アップロード済み素材の小さなプレビュー表示
- 透明余白を自動トリミング
- 透明部分を無視して素材のメインカラーを自動抽出
- 白・黒・グレーをなるべく除外して3種類のパレットを作成
- やわらかカラー、くっきりカラー、ナチュラルカラーを選択
- 抽出カラーをタイトル、サブタイトル、アクセントに反映
- 雰囲気プリセットを選択
- タイトルとサブタイトルのフォントを個別に選択
- Google FontsをCSS importで利用
- タイトルとサブタイトルの位置、サイズ、間隔をスライダーで調整
- デスクトップではプレビューを固定表示しながら編集
- グリッド容量を超えた素材をページ分割
- ページごとにプレビュー、ダウンロード
- 保存サイズを1000px、2000px、3000pxから選択
- 保存形式をPNG、JPGから選択
- 文字あり版と文字なし版をそれぞれPNGでダウンロード
- Etsy向け正方形サムネイルを書き出し
- すべてブラウザ内で処理し、APIへ画像を送信しません

## プリセット

- Watercolor Baby（水彩ベビー）
- Vintage Gouache（ヴィンテージガッシュ）
- Halloween Cute（ハロウィン）
- Christmas Cozy（クリスマス）
- Minimal Line Art（線画）
- Pastel Nursery（パステル）
- Bold Kids Party（ポップ）

各プリセットでタイトルカラー、サブタイトルカラー、余白バランス、全体の雰囲気が変わります。

## フォントカテゴリ

- 手書き風
- 筆記体
- かわいい
- ベビー向け
- シンプル
- 太字
- ナチュラル
- ヴィンテージ

有料フォントやローカルフォントファイルは使わず、Google FontsとWeb-safeなフォールバックフォントを使用しています。

ベビー向けフォントには `Chewy` と `Bubblegum Sans` を含む、シンプルとは違う丸くかわいいフォントスタックを使用しています。

## カラーパレット

アップロードしたPNG素材から、以下の3種類のパレットをブラウザ内で生成します。

- やわらかカラー: ベビー、ナーサリー、水彩向け
- くっきりカラー: ハロウィン、キッズ、ポップ向け
- ナチュラルカラー: ヴィンテージ、ガッシュ、自然素材向け

選択したパレットは、タイトル色、サブタイトル色、UIのアクセントカラーに反映されます。アップロードした素材そのものの色は変更しません。

## レイアウト

- 自動
- 4×3
- 4×4
- 5×4

自動レイアウトの目安:

- 30〜40 PNG: 4×3
- 41〜60 PNG: 4×4
- 61〜90 PNG: 5×4

ページ容量:

- 4×3: 1ページ12枚
- 4×4: 1ページ16枚
- 5×4: 1ページ20枚

素材数がページ容量を超えると、自動でページが追加されます。

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## ビルド

```bash
npm run build
```

## Vercelへデプロイ

1. このフォルダをGitHubリポジトリにアップロードします。
2. [Vercel](https://vercel.com) で新しいプロジェクトを作成します。
3. GitHubリポジトリをインポートします。
4. Framework Preset は `Next.js` のままでOKです。
5. 通常は以下の設定でデプロイできます。
   - Install Command: `npm install`
   - Build Command: `npm run build`
   - Output Directory: `.next`
6. `Deploy` を押すと公開URLが発行されます。

このアプリはNext.js / React / TypeScript / HTML Canvasで作られており、Vercelにそのままデプロイできます。
